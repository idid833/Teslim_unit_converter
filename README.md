# Engineering Unit Converter

## What it does

The Engineering Unit Converter is a Python program that converts different engineering measurements from one unit to another. It converts millimetres to inches, Celsius to Fahrenheit, kilograms to pounds, and kilometres per hour to metres per second.

The program uses a simple menu that allows users to select their preferred conversion. It also stores previous conversion results in a conversion history.

## How to run it

1. Install Python 3 on your device.
2. Download or copy the file named `engineering_unit_converter.py`.
3. Open your Python editor (e.g. Pydroid 3).
4. Run the program.

You can also run it using the terminal:

python engineering_unit_converter.py

## my own twist

I added a Conversion History feature that stores previous conversion results. Users can select option 9 from the menu to view their previous conversions without performing them again.

I also included input validation to prevent the program from crashing when users enter invalid values.
